# First 30 days

What I would do in the role, using the desk as the working surface. Also shown in the app at `#/value`.

| Days | Focus | Output |
| --- | --- | --- |
| 1–5 | Sit with each strategic seller; list their real top accounts; agree the three-active rule with the sales leader | Nine named campaigns, owners and dates |
| 6–10 | Map buying committees from public sources; mark every unknown seat | Committee map per account with sourced evidence |
| 11–15 | Build the route ledger with investors, advisors, partners, customers and team networks; verify nothing without the introducer's own word | Route ledger: verified / public affiliation / hypothesis |
| 16–22 | Agree signal shelf lives with marketing and events; tie each upcoming event to a named campaign | Signal desk and event seats with owners |
| 23–30 | Run the Monday review from the desk; report measures with denominators; propose the CRM fields that would close the outcome gap | First weekly report; CRM field proposal |

What I would not do: send cold executive notes, set call targets, or report pipeline I cannot source.
